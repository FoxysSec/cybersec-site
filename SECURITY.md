# Security Policy

## Escopo

Este repositório é um portfólio e laboratório educacional de cibersegurança. Os exemplos públicos devem usar somente ambientes próprios, locais ou explicitamente autorizados.

## Dados que não devem ser publicados

Nunca publique neste repositório:

- senhas ou credenciais;
- tokens, API keys ou secrets;
- chaves privadas SSH/TLS;
- cookies ou tokens de sessão;
- arquivos de configuração contendo segredos;
- endereços IP públicos ou detalhes desnecessários da infraestrutura pessoal;
- MAC addresses ou identificadores pessoais de dispositivos;
- dumps, logs ou relatórios que contenham dados pessoais.

Resultados de laboratório devem ser anonimizados antes da publicação.

## Divulgação responsável

Se um problema de segurança for encontrado neste projeto, não publique credenciais ou dados sensíveis em issues ou pull requests. Entre em contato com o mantenedor por um canal privado disponível no perfil do GitHub.

## Regra dos laboratórios

Os testes documentados devem permanecer dentro de ambientes autorizados. Técnicas apresentadas aqui não constituem autorização para testar sistemas de terceiros.
